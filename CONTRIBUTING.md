# Contributing to Ajiputra-Project MovieBox API

🎉 First off, thanks for taking the time to contribute! 🎉

The following is a set of guidelines for contributing to **Ajiputra-Project MovieBox API**.

## 🛠️ How Can I Contribute?

### Reporting Bugs
- Use the [GitHub Issues](https://github.com/ajiputra001/MovieBox-Api/issues) to report bugs.
- Describe the expected behavior and actual behavior.
- Include steps to reproduce the issue.

### Pull Requests
1. **Fork the repository** (`https://github.com/ajiputra001/MovieBox-Api.git`) and create your branch from `main`.
2. **Ensure the test suite passes** by running `python verify.py`.
3. **Issue a pull request!**

---

*Thank you for contributing to Ajiputra-Project!*
